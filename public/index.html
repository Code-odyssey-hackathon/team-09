Features

Everything You Need to
Protect Your Crops

From AI detection to actionable advice — a complete crop health toolkit.

🔬

5-Class Stress Detection

Classifies leaf images into Healthy, Drought Stress, Nutrient Deficiency, Pest Attack, or Fungal Disease using MobileNetV2.

📊

Severity Scoring

Returns a calibrated 0–100 severity score per stress category so you know exactly how urgent the situation is.

💊

Treatment Advice

Expert-level, stress-specific recommendations — irrigation schedules, fertilizers, pesticides, and fungicides.

🌦️

Real-Time Climate Alerts

Integrates OpenWeatherMap to surface weather-based crop risk warnings for heat, frost, humidity, and wind.

📱

Drag-and-Drop UI

Clean, responsive interface with image preview, animated severity ring, and confidence bar — works on any device.

⚡

Serverless Architecture

Zero-ops deployment on Vercel — Python API auto-scales from zero to handle inference at the edge, globally.

How It Works
